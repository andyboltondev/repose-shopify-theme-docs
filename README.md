# Repose theme documentation

Documentation and issue tracking for **Repose**, a Shopify theme by Andy Bolton.

Repose ships three presets, each designed for a different kind of shop:

| Preset | Suits |
| --- | --- |
| Repose | Home and interiors |
| Selvedge | Clothing |
| Nacre | Jewellery and accessories |

## Documentation

Start at [documentation/](documentation/) for setup, theme settings and
section-by-section reference.

## Reporting an issue

Found a bug, or something in the documentation that does not match what the
theme does? [Open an issue](https://github.com/andyboltondev/repose-shopify-theme-docs/issues/new/choose).

When reporting a bug, the two most useful things you can include are the theme
version, shown in **Online Store > Themes** next to the theme name, and a link
to a page on your storefront where the problem is visible. If your store is
password protected, include the password so the page can be reached.

Please do not include order details, customer information or admin credentials
in an issue. Issues here are public.
