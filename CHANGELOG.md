# Release notes

Every released version of Repose, newest first. Each entry leads with what
changed for merchants rather than with implementation detail.

Repose uses semantic versioning: the first number changes when an update needs
work from you after updating, the second when features are added, the third for
fixes alone.

## 1.0.0

The first release of Repose.

**Three presets, one modular theme.** Repose for homeware, Selvedge for
clothing and Nacre for jewellery. Each preset is a complete design system
(light and dark palettes, typography, spacing, button and card shape) on top
of the same sections, blocks and settings, so everything described below works
with every preset.

**Light and dark mode.** A hand-tuned palette for each mode, a header toggle,
and an optional "follow the system setting" default. The shopper's choice is
remembered and applied before the page first paints.

**Product page.** Variant-specific images, thumbnails below or to the left,
three zoom styles (loupe, lightbox and external zoom), a sticky information
column, a sticky add to cart bar, a metafield-driven accordion for
specifications, care and sizing, product ratings, a trust row, share buttons,
app blocks, and an editorial product template for flagship products.

**Colour swatches.** Colour, metal and similar options show as swatches on
the product page and, optionally, on product cards and in filters. Swatches
use Shopify's own swatch colour or image when you have set one, and otherwise
the image of the variant each value selects, so no extra data entry is needed.
Choose which options count as swatches and their shape in theme settings.

**Variant media groups.** Choose which images show for which variant by
adding a rule to an image's alt text, for example `#"Colour" is "Blue"`.
Rules support `is`, `not`, `and`, `or` and parentheses, and the description
before the rule is all shoppers and screen readers receive.

**Collections and search.** Shopify's native filtering and sorting on both
collection and search pages, badges for sale, sold-out, pre-order and
back-order products, optional quick add on product cards, a second image on
hover, and an editorial collection template.

**Cart.** A slide-out cart drawer (or a compact minicart, or straight to the
cart page) with complementary product recommendations, a free shipping
progress bar, an order note and accelerated checkout.

**Navigation.** A three-level mega menu, a nested mobile menu, a sticky header,
an announcement bar and a search dialog.

**Pages.** About, FAQ, landing, sitemap and contact page templates, plus a
full set of customer account pages.

**International.** Country or region and language selectors, and translations
for English, French, German, Italian and Spanish.

**Fast and accessible.** No JavaScript framework, fonts from Shopify's library,
responsive images sized to the grid, full keyboard support including the mega
menu, focus-trapping dialogs, and all motion disabled when a shopper asks for
reduced motion.
