# Release notes

Every released version of Repose, newest first. Each entry leads with what
changed for merchants rather than with implementation detail.

Repose uses semantic versioning: the first number changes when an update needs
work from you after updating, the second when features are added, the third for
fixes alone.

## Unreleased
