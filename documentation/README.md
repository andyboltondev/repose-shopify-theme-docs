# Repose documentation

Repose is a Shopify Online Store 2.0 theme built from sections and blocks, so
almost everything on your storefront is arranged and configured from
**Online Store > Themes > Customize**, without touching code. This
documentation explains what the theme does, what every setting affects, and
how the more involved features work.

## How the theme is organised

Repose ships three presets, each suited to a different kind of shop. Presets
change colours, fonts, spacing and other presentational choices, not which
sections a page contains:

| Preset | Suits |
| --- | --- |
| Repose | Home and interiors |
| Selvedge | Clothing |
| Nacre | Jewellery and accessories |

Your storefront is built from **templates** (one per page type: home, product,
collection, and so on), each holding a list of **sections**, and some sections
accept **blocks** you can add, remove and reorder. All of this happens in the
theme editor. Nothing in this documentation requires editing theme code.

## Reporting an issue

Found a bug, or something in the documentation that does not match what the
theme does? [Open an issue](https://github.com/andyboltondev/repose-shopify-theme-docs/issues/new/choose).

When reporting a bug, the two most useful things you can include are the theme
version, shown in **Online Store > Themes** next to the theme name, and a link
to a page on your storefront where the problem is visible. If your store is
password protected, include the password so the page can be reached.

Please do not include order details, customer information or admin credentials
in an issue. Issues here are public.
