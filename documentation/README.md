# Repose documentation

This documentation is being written alongside the theme and is not complete
yet. Pages are listed here as they land, so an absent page means unwritten
rather than missing.

## Planned contents

| Page | Covers |
| --- | --- |
| Installation | Adding Repose to your store and choosing a preset. |
| Theme settings | Every setting in **Customize > Theme settings**, and what it affects. |
| Sections and blocks | Each section, the blocks it accepts, and how to arrange them. |
| Products and collections | Product pages, variant options, filtering and search. |
| Navigation and menus | Header, menus, mega menu and footer. |
| Images and video | Recommended sizes, focal points and file formats. |
| Accessibility | What the theme handles, and the choices that are yours to make. |
| Performance | Keeping a customised store fast. |
| Troubleshooting | Common problems and how to resolve them. |

If you need something that is not documented yet, please
[open an issue](https://github.com/andyboltondev/repose-shopify-theme-docs/issues/new/choose)
and it will be answered and then written up here.
